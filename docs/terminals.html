Terminals and the dock

Artisan, a console, Tinker and every log, in a dock at the bottom of the window, a key away.

The dock

Terminals live in a dock at the bottom of the window. An application's page header opens them:

  • Artisan: Laravel's commands with their forms. It offers your models, tables, views, components and route names as you type. A Symfony application has bin/console in the same place.
  • Console: an interactive shell for the application.
  • Tinker: Laravel's REPL.
  • Logs: every log the application has, in one list; see Logs.

Artisan and Tinker show only for a Laravel application. Clicking anywhere outside an open terminal minimises it to its badge in the dock; the badge brings it back. The code editor minimises there too.

The dock's hide button tucks it behind a small handle that shows how many items it holds, and the dock remembers whether you hid it. Settings › Appearance › Show other applications in the dock is on by default; turn it off and an application's page docks only its own terminals and editors, while the others keep running.

Console tabs

The Console has tabs, each its own shell in the application's folder, so you can run commands in one and keep something like Claude Code running in another. Tabs keep running, at their size, while you are in another, in the dock or inside the editor.

  • + or Ctrl+Shift+T (Cmd+Shift+T on macOS) adds a tab.
  • Ctrl+PageDown and Ctrl+PageUp move between them (Cmd+Shift+] and Cmd+Shift+[ on macOS).
  • Double-click a tab, or press F2, to rename it.

Inside the code editor

The code editor's toolbar has Console, Artisan, Tinker and Logs buttons for the application you are editing, each showing your key bind for it. They open over the editor. Turn on Editor settings › General › Open terminals inside the editor and they open as a resizable panel under the code instead. It is the same session as in the dock, so minimising the editor hands it back to the dock without restarting it, and keys typed in it never trigger the editor's shortcuts.

The cursor

Settings › Appearance › Terminal cursor sets a block, underscore or pipe, in Phun's red or the text colour, and whether it blinks, with a preview. Open terminals change at once.

Keys

  • ` opens the Console for the application you are on, and closes it again, even from inside it.
  • Shift+` moves to its next open terminal.
  • Ctrl+Up hides and shows the dock, on macOS too.
  • Settings › Key binds can give your own keys to opening every terminal at once, the code editor, minimising the terminal and hiding the dock.

Logs

Logs gathers every log the application has into one list you can filter and search, with stack traces that open the editor; see Logs.

History and Run again

Commands run in an application's terminals are kept in its history (phun history blog). The command palette's Run again group lists the Artisan commands you ran recently, so a repeat is Ctrl+K, a few letters and Enter.
