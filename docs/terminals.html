Terminals and the dock

Artisan, a console, Tinker and every log, in a dock at the bottom of the window, a key away.

The dock

Terminals live in a dock at the bottom of the window. An application's page header opens them:

  • Artisan: Laravel's commands with their forms. It offers your models, tables, views, components and route names as you type. A Symfony application has bin/console in the same place.
  • Console: an interactive shell for the application.
  • Tinker: Laravel's REPL.
  • Logs: every log the application has, each in its own tab.

Artisan and Tinker show only for a Laravel application. Clicking anywhere outside an open terminal minimises it to its badge in the dock; the badge brings it back. The code editor minimises there too.

Keys

  • ` opens the Console for the application you are on, and closes it again, even from inside it.
  • Shift+` moves to its next open terminal.
  • Settings › Key binds can give your own keys to opening every terminal at once, the code editor, minimising the terminal and hiding the dock.

Logs

Logs shows the application's own log (Laravel's, or Symfony's var/log), PHP's, and those of its queue workers, scheduler, Reverb, Messenger and tunnel. Every file and line in a stack trace inside the application opens the editor there. Exceptions lists each exception once, with how often it was thrown and when last. Each log can be emptied.

phun logs blog laravel
phun logs blog queue --clear

History and Run again

Commands run in an application's terminals are kept in its history (phun history blog). The command palette's Run again group lists the Artisan commands you ran recently, so a repeat is Ctrl+K, a few letters and Enter.

phun console blog migrate:status  # artisan or bin/console, on the application's PHP
