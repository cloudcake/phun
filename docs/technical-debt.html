Technical Debt

The work your team put off and noted in the code, beside the code smells and deprecated PHP Phun finds, with a fix where one is safe.

What your team noted

Each application has a Technical Debt tab. It lists the work your team put off and noted in the code: unfinished work, needed fixes, workarounds, things needing attention and known bugs. Each item shows its file and line, who it is for and what it says, grouped by file. Filter by kind, or search. An application with nothing noted gets a small celebration instead.

What Phun finds

Beside your team's notes, Phun lists:

  • Unused imports, and formatting that does not match the application's own Pint when it has one. An application not formatted with its Pint shows as one item.
  • Debugging calls left in, errors caught and dropped, commented-out code and silenced warnings.
  • Very long functions and files, and, in Laravel, env() read outside a config folder.
  • A missing blank line after a variable, or a run of them, before the next statement.
  • Deprecated PHP, from PHP 8.1 to 8.5, saying whether it already warns on the application's PHP or only will on a newer one. Deprecated PHP shows as high severity, in red.
  • A composer.json that requires a PHP the application does not run on, or pins Composer to a different PHP.

Act on an item

Select an item to see its code with the line marked, then open the editor at that line or apply its fix. A Fix button makes the change where it is safe, such as a nullable parameter type, a cast's new name, a ${} in a string or the missing blank line.

Each line names who last changed it, from git, and you can search by that name. Changes not committed yet say so.

Results

The list shows straight away, while the application's own Pint runs beside it, and the tab says what it is still reading. Results stay when you leave the tab and come back; Read again, a fix or a new PHP version reads afresh.
