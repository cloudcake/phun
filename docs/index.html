What Phun is

Your PHP applications, on your own machine

Phun runs your PHP applications on your own machine. Every folder you link is served at its own .test address over trusted HTTPS, with the PHP version it needs, and the databases, cache, search and mail it uses run beside it as native processes. It is one desktop app with a small background service and a phun command for the terminal. No Docker, no virtual machine, and no password for everyday work.

Link a folder, or park them all

Link a folder, or park a whole directory, and every project in it is served at name.test. The web root is found for you.
