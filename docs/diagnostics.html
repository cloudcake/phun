Diagnostics and notifications

Health checks with a fix for each, a problem report with the secrets taken out, and notifications for what happens in the background.

Health checks

Diagnostics, on the Overview (Ctrl+3), runs Phun's checks for DNS, certificates, ports and PHP, each with a one-click fix when something is off. The palette can run the safe fixes too.

phun status  # the daemon, ports, DNS, certificates and PHP at a glance
phun doctor
phun doctor fix

A problem report

Diagnostics › Report gathers what a bug report needs in one file: versions, services, Phun's processes, a .test lookup, health checks and recent logs. Passwords, tokens, keys, email addresses, share links, card or ID numbers and your user name are removed before you see it. Copy it, or Save file puts it in Downloads. Copy diagnostics on the daemon panel is redacted the same way. Problems and ideas are welcome in Discussions.

When the daemon will not start

Phun checks, stops what is left and starts it directly. Copy diagnostics lists every start attempt with its time, so a report shows what was tried. After an in-app update, the daemon's panel can also go back to the version you had; see Going back.

phun ping
phun restart daemon

Notifications

What happens in the background arrives as a desktop notification, even with the window closed:

  • Queued jobs finishing or failing, Messenger messages handled or given up on, and scheduled tasks failing.
  • Caught mail, and errors in an application's log.
  • A service or worker stopping, installs and new applications finishing or failing, and shares ending.
  • A new Phun release.

Settings › Notifications turns each kind on or off and has Do not disturb. A burst of one kind becomes one notification. Scheduled tasks that succeed start switched off, since a task that runs every minute would notify every minute.

phun events  # the recent background events
